# Career Compass

Create a modern, premium, responsive AI-powered Job Portal website named "JobVerse" (placeholder name, easy to change later).

The website should have a clean, modern, professional, and trustworthy design inspired by LinkedIn Jobs, Indeed, Glassdoor, Wellfound, and RemoteOK while maintaining a unique identity.

The UI should be built using modern SaaS design principles with a white, blue, and dark accent color palette. Use large rounded cards, soft shadows, glassmorphism effects where appropriate, premium typography (Poppins for headings and Inter for body text), generous white space, smooth hover effects, and subtle animations.

The design must be responsive for Desktop, Tablet, and Mobile and should be easy to recreate later in WordPress using Elementor.
